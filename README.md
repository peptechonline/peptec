# Pep Tech Solution Blog — Starter Website

A responsive single-page blog homepage concept inspired by the BloggDude structure and adapted to the publicly visible subject matter of the Pep Tech Solution YouTube channel.

## Preview
Open `index.html` in a browser.

## Included
- Responsive navigation and mobile menu
- Hero section and YouTube subscribe CTA
- Topic/category cards
- Selected YouTube video cards with thumbnails and links
- Embedded YouTube video
- Searchable starter article cards
- About section and newsletter demo
- Footer and basic SEO metadata

## Before publishing
1. Replace placeholder contact email `hello@example.com`.
2. Create real Privacy Policy, Terms and Affiliate Disclosure pages.
3. Connect the newsletter form to MailerLite, Fluent Forms, or another provider.
4. Replace the sample article outlines with original, verified tutorials.
5. Confirm each video is still public and relevant.
6. Add your own logo, brand colors, author details and social links.
7. Deploy to WordPress or static hosting; this folder is a front-end prototype, not a configured WordPress installation.

The page uses externally hosted YouTube thumbnails and an embedded YouTube player, so those elements require an internet connection.
